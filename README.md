# Basics Showcase

This repository serves as a laboratory for front-end fundamentals. Each experiment is a deliberate step toward mastering the building blocks of the web. The experiments range from simple static layouts to lightly interactive pieces. 

*Live site*: **https://basics-showcase.vercel.app/**

*Projects:* **https://github.com/njokinjeri/basics**

## Project Sources

Many of the projects are inspired by or adapted from challenges on:

- [Frontend Mentor](https://www.frontendmentor.io/)

- [Dev Challenges](https://devchallenges.io/)

## Tech Stack

- HTML: semantic structure and accessibility

- CSS: layout, styling, and responsive design

- JavaScript: DOM manipulation and interactivity

**Project-specific: Netlify for secure API handling**

## Structure

Each project is contained in its own folder and typically includes:

- index.html

- styles.css

- script.js (depending on the project)

The showcase site provides links to these projects and presents them in a simple, and easy-to-navigate layout.
